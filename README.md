# bring-the-humans-03 — ad assets (awaiting production + the TikTok post)

`SCRIPT.md` is the storyboard, voiceover lines and caption for a ~28s
vertical TikTok ad for make.fun. The entry is the posted video itself:
`main.ts` copies `VIDEO.json` to /output, and `VIDEO.json` gets the video's
TikTok URL once it is posted publicly. The official press-pack brand badge
(first frame) and referral end card (last frame, referral code in its field)
still have to be composited in, and the post has to come from the person's
own public TikTok account — see SCRIPT.md, "Still needed".
